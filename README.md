# Projet Événementiel & Wedding Planning

Espace de travail pour construire l'activité d'organisation d'événements et de mariages.

## Organisation des dossiers

| Dossier | Contenu |
|---|---|
| `01-strategie/` | Vision, positionnement, étude de marché, business plan |
| `02-offres-services/` | Formules, packages, tarifs |
| `03-marketing/` | Identité de marque, site web, réseaux sociaux, campagnes |
| `04-clients/` | Suivi des demandes et des clients (sans données sensibles) |
| `05-prestataires/` | Carnet de prestataires : traiteurs, salles, photographes, fleuristes… |
| `06-evenements/` | Fiches événements, rétroplannings, check-lists, modèles |
| `07-finances/` | Budgets, devis types, prévisionnels |
| `08-administratif/` | Statut juridique, contrats types, assurances, CGV |

## Bonnes pratiques

- Ne pas stocker de données personnelles sensibles (pièces d'identité, coordonnées bancaires).
- Un fichier = un sujet ; noms de fichiers en minuscules avec tirets.
